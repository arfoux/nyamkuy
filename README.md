# 🍳 NyamKuy

NyamKuy adalah web aplikasi yang menampilkan **resep masakan random** untuk membantu pengguna menemukan ide masakan setiap hari. Dibangun menggunakan **Next.js**.

---

## 🚀 Fitur

* 🎲 Random resep masakan

---

## 🛠️ Tech Stack

* Next.js
* React
* Tailwind CSS
* Node.js

---

## 📦 Instalasi

Clone repository:

```bash
git clone https://github.com/username/nyamkuy.git
cd nyamkuy
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Menjalankan Project

Jalankan development server:

```bash
npm run dev
```

Buka di browser:

```
http://localhost:3000
```
